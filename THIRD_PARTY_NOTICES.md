# Third-party artwork

Emoji graphics use [Twemoji](https://github.com/jdecked/twemoji), copyright Twitter, Inc. and other contributors, under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). The application displays unmodified SVG artwork from the version 17.0.3 release through jsDelivr. Native Unicode remains the fallback if an image cannot load. This is a consistent replacement emoji set; it is not Apple's proprietary artwork.
